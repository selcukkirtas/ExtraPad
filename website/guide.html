1. Set up the Mac

ExtraPad runs quietly in the menu bar. It needs two permissions to work — both are one-time, standard macOS prompts.

01

Open ExtraPad

It adds a small icon to your menu bar and starts immediately — there's no window to set up.

02

Grant Screen Recording

macOS asks for this the first time ExtraPad tries to capture a display. Without it, the menu shows Screen Recording permission required and nothing streams.

System Settings → Privacy & Security → Screen Recording → turn on ExtraPad
03

Grant Accessibility

This is what lets a touch on the iPad move your Mac's cursor. Skip it if you only want to view the screen, not control it.

System Settings → Privacy & Security → Accessibility → turn on ExtraPad
04

Note the address and code

Click the menu bar icon — it shows the address to open on the iPad, and a six-digit pairing code underneath.

!

Launched it and the menu still says Screen Recording permission required after granting it? Quit ExtraPad fully (menu → Quit) and open it again — macOS only re-checks the permission for a fresh launch.

2. Connect an iPad

Which path you use depends on the iPad, not on anything you choose.

iOS 15 and newer

Native app

Open the ExtraPad app. It finds Macs on the network on its own — tap the one you want, enter the six-digit code once, and it remembers this Mac from then on.

iOS 9 – 14

Safari

Type the address shown in the Mac's menu bar into Safari. Enter the code when asked. Use Share → Add to Home Screen to get an icon for it afterward.

i

The code only has to be entered once per iPad. After that, both the native app and the Safari shortcut reconnect on their own whenever the Mac is reachable.

3. Use it as a display

Once connected, the iPad shows up as an ordinary monitor.

01

Find it in Displays

System Settings → Displays lists it alongside your other monitors, named after the iPad that's using it.

02

Drag a window over

Treat it exactly like a second monitor — position it in Displays, drag windows on and off it.

03

Touch to control

One finger on the iPad moves the Mac's cursor. On the native app, double-tap to show or hide the small status bar at the top.

4. Trials and licenses

ExtraPad's menu bar icon always shows where you stand — Trial: N days left, Licensed ✓, or Not licensed.

01

Start a trial

Menu → Start 14-Day Free Trial… opens a free checkout — no card needed. The key arrives by email; paste it into Enter License Key… to activate.

02

Buy a license

Menu → Buy a License… for the $19 lifetime license. Same activation step as the trial, just a key that never expires.

03

Move it to a new Mac

A license runs on one Mac at a time. Activating it on a new one deactivates the old automatically — or use Menu → Deactivate license on this Mac… first if you'd rather do it by hand.

04

Lost the key?

Look up your order with the email you purchased with on your LemonSqueezy order page — it's shown there regardless of whether you still have the original email.

5. Troubleshooting

The iPad app says "Nothing found yet"

This almost always means ExtraPad isn't actually open on a Mac on the same network yet — check the menu bar. If it is open, confirm both devices are on the same Wi-Fi network, not one of them on cellular or a guest network.

Safari asks for the code again on every visit

The code is remembered through a cookie. If Safari's "Prevent Cross-Site Tracking" or a content blocker is clearing it, add the ExtraPad page as an exception, or use Add to Home Screen — that shortcut keeps its own storage.

"A TLS error caused the secure connection to fail"

This clears itself on the next automatic reconnect attempt in almost every case - the app retries with a fresh connection a few seconds later. If it's still showing after a minute, quit and reopen the iPad app.

Touch moves the cursor on the wrong display

Input follows whichever iPad touched the screen most recently. If two iPads are connected, the one you're not touching simply won't move the cursor until you touch it instead - that's expected, not a bug.

The picture is there but touch does nothing

Accessibility permission either wasn't granted or was granted before a restart that's needed to take effect. Check System Settings → Privacy & Security → Accessibility, then quit and reopen ExtraPad.

Displays stopped working after the trial

Expected - every connected iPad disconnects when the trial or license lapses. Start a new trial or enter a license key from the menu bar and reconnect; nothing about your setup is lost.
